Owning problems end‑to‑end

How I work: understand the real problem, ship the whole thing, then keep it running.

I'm a full-stack engineer who is most useful when handed a messy, real-world problem and the freedom to own it. I work across the whole stack — schema and API design, responsive UIs, third-party integrations, and the cloud infra underneath — and I care about code that's still easy to reason about six months later. I founded and built TradeXJournal solo: an AI-powered trading platform with its own auth, billing, backtesting engine, and live broker execution, running on Azure with CI/CD I maintain. Alongside it I run Personalize Algo, an automated trading system that trades NSE equities with real capital every market day — which means the edge cases, charge reconciliation, and the 08:00 token refresh are mine to get right.
